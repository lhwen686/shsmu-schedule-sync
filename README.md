# 医学院课表助手

**双击一个软件，把本人的教务课表导入 iPhone 的 WakeUp 或自带日历。**

学生版面向 Windows 64 位电脑，不需要安装 Python、使用命令行或修改配置文件。使用平时登录教务的浏览器，适用于上海交通大学医学院本科教务系统 jwstu.shsmu.edu.cn。

**[点击下载 Windows 完整软件包](https://github.com/lhwen686/shsmu-schedule-sync/releases/download/v1.0.0-rc7/SHSMU-Schedule-Assistant-1.0.0-rc7-Windows-x64.zip)**。下载后右键选择“全部解压缩”，里面就是中文命名的软件和使用说明。单独下载软件或查看图文说明，请到 [下载页](https://github.com/lhwen686/shsmu-schedule-sync/releases/tag/v1.0.0-rc7)。

当前为 **1.0.0-rc7 候选版**，增加书签操作、WakeUp 作息与学期日期的重点提醒，并用大白话说明遇到安全软件提醒时该怎么办。自动检查和实机验收分开记录，尚未完成的环节见 [学生版验收](STUDENT_ACCEPTANCE.md)。原命令行工具继续可用，安装与维护命令见 [维护说明](MAINTENANCE.md)。

本分支为 **1.0.0-rc8 本地修复候选版，尚未发布**：补齐首次引导页的已下载 JSON 导入入口，以及下载后继续导出的提示。上方公开下载仍为 rc7，旧版也可按下方步骤处理已下载文件。

更新助手后，按安装页指引手动替换书签，才会显示新版下载提示；已有 JSON 可直接选择并处理。

## 第一次使用

1. 下载上方完整 ZIP 包，右键选择“全部解压缩”，再双击其中的 **医学院课表助手.exe**。如果选择单独下载 EXE，直接双击该文件即可。
2. 选择要导入的学期，**不用填写哪天结课**。当前默认 2026–2027 学年第 1 学期，助手按学校校历准备采集范围，并包含下学期开学前的寒假；实际有课到哪天由本人教务课表确定。
3. 点 **复制安装页地址**，在平时登录教务的浏览器地址栏粘贴并回车。安装页会先检查基础功能；按图示把绿色“同步医学院课表”按钮拖到书签或收藏夹栏，再回助手点 **我已添加课表按钮**。

首次获取课表尚未完成时，重新打开软件会继续显示书签安装引导；只有成功保存过完整课表后，才会默认进入更新首页。

杀毒软件有时会把正常软件当成病毒。请使用作者发的软件或下载链接。如果出现提醒、拿不准该点什么，把提示截图发给作者，确认后再继续打开。

Edge 叫“收藏夹栏”，Chrome 叫“书签栏”，Firefox 叫“书签工具栏”，可按 **Ctrl + Shift + B** 显示。添加和学校登录请使用同一个浏览器；换浏览器时重新添加按钮即可，助手里的历史无需搬动。安装页也提供手动替换旧书签的方法，助手不会修改浏览器或扩展。

## 以后更新课表

1. 在助手点 **获取我的课表**，看到“已准备好接收”。
2. 在添加了课表按钮的浏览器中正常登录 [教务首页](https://jwstu.shsmu.edu.cn/Home)，看到本人学号后，**务必点击书签栏 / 收藏夹栏中的“同步医学院课表”**，才会开始采集。保持学校页面打开，等待几分钟，以网页实际进度为准。
3. 助手分别显示两种文件的状态。点 **导出 WakeUp 文件**，定位 **wakeup.csv**；或点 **导出苹果日历**，定位 **calendar.ics**。在首页也能找到这两个入口，不用重新采集。

## 在 iPhone 导入 WakeUp

1. 将选中的 wakeup.csv 通过微信“文件传输助手”或 QQ“我的手机”发给自己，再保存到 iPhone 的“文件”App。
2. WakeUp → **导入课表 → Excel 导入 → 选取 CSV 文件**，导入到新课表。
3. 在助手查看 **WakeUp 导入指引与作息**。开学日期根据教务教学周校验，WakeUp 所需周数按本次最后有课的教学周计算；照设置卡核对这些值及上课时间。
4. 检查第一周、晚课和不连续周次，核对后再自行处理旧课表，避免重复显示。

**电脑生成文件后，手机仍要手动导入。** CSV 不携带作息设置，也不会自动更新手机。全部实际课程起止时间都会与作息核对，模板中未获课程端点证实的时间标为推算。

**WakeUp 导入后，请手动改这两项：** 显示的 **50 分钟**来自 WakeUp 当前作息设置，当前默认模板应为**每节上课 40 分钟**；本学期第一天应设为 **2026 年 9 月 7 日（9.7），不要保留 9 月 4 日（9.4）**。打开助手的“查看 WakeUp 导入指引与作息”，找到本次课表的设置卡，逐节核对上下课时间。其他学期或自定义作息以本次设置卡为准。若无法单独修改下课时间，在 WakeUp 关闭“每节课时长相同”。已经导入课表的同学修改这两项即可，无需重新采集或重复导入。

配图步骤见 [使用说明](使用说明.html)。手机操作依据：[WakeUp CSV 导入](https://www.wakeup.fun/doc/import_from_csv.html)、[课表设置](https://www.wakeup.fun/doc/settings/schedule_settings.html)。

## 在 iPhone 导入苹果日历

1. 在 iPhone“日历”中建立专用的 **医学院课表** 日历。
2. 在助手点 **导出苹果日历**，将选中的 **calendar.ics** 作为邮件附件，由你发送到自己的邮箱。
3. 在 iPhone 自带 **邮件** App 中打开附件，按提示导入专用课表日历。仅预览到文件内容不代表已导入。
4. 在助手打开 **苹果日历导入指引**，核对课程日期、上课时间、地点和教师。ICS 已携带每次课的日期、起止时间和上海时区，无需填写开学日期或节次作息。

**这是一次性导入，不会自动更新手机。** 以后更新时，先导入新的专用课表日历，核对后再由你隐藏或移除旧课表日历，避免重复显示。不能保证重复导入自动覆盖原课程或删除取消课程，请特别核对发生变化的课程。

两种文件独立检查：WakeUp 作息设置不匹配时，有效的苹果日历文件仍可使用。两种“手机已导入”确认分别记录，仅代表你的手工核对。苹果日历邮件附件实机导入及重复导入行为仍待本版验收。

官方依据：[从“邮件”导入 ICS](https://support.apple.com/zh-cn/guide/iphone/ipha0d932e96/ios)、[在 iPhone 设置多个日历](https://support.apple.com/zh-cn/guide/iphone/iph3d1110d4/ios)。

## 遇到问题

### 只下载到 shsmu-capture-…json，没有 WakeUp 或日历文件

这是浏览器采集的中间文件，还需要交给电脑上的助手处理。

1. 打开 **医学院课表助手.exe**，点 **遇到问题 → 文件已经下载**；新版首次书签引导页和首页也有 **文件已经下载**。
2. 选择刚刚下载的 **shsmu-capture-…json**，等待助手核对并生成文件。不用重新采集，也不要改扩展名。
3. 点 **导出 WakeUp 文件** 获取 **wakeup.csv**，或 **导出苹果日历** 获取 **calendar.ics**，按上面的手机步骤导入。

这两个文件由助手保存在本机数据目录的 `output` 文件夹，导出按钮会定位相应文件，不会另出现在浏览器下载列表。若助手显示处理错误，保留具体提示供排查；仅凭 JSON 文件名不能确认内容完整。

| 情况 | 在助手里怎么做 |
| --- | --- |
| 已先点书签，文件下载好了 | 点“文件已经下载”；取消选择会继续原来的等待 |
| 文件保存在别处 | “遇到问题”→“选择下载文件夹”，或直接选择已下载文件 |
| 换了浏览器后找不到课表按钮 | “遇到问题”→“重新查看书签安装引导”，在新浏览器添加并登录 |
| 安装页显示当前浏览器不能使用 | 按提示使用更新后的普通浏览器窗口，避开 IE 兼容模式 |
| 课表保存了，WakeUp 文件没生成 | 在设置中核对作息，再点“重新生成导入文件”；有效的苹果日历文件仍可使用 |
| 苹果日历文件缺失、被修改或不可用 | 点“重新生成导入文件”，从已保存课表恢复；写入失败时检查磁盘空间和文件夹权限 |
| 登录账号与原课表不同 | 登录原账号；另一人选择独立空目录 |
| 以前使用过源码版 | 在首次引导或“设置 → 保存位置”选择原项目目录，沿用历史 |
| 学期变了 | 在设置中填写新学期及包含的最后一天，保存后按引导更新书签 |

当前秋季自动采集覆盖 2026-09-07 至 2027-02-21（含），依据学校校历的下一学期开学日。1 月 17 日是校历中的秋季教学期末，不是每个人的结课日；提前结课不会生成空课，寒假期间的同学课程也会读取。此范围不代表学校已经公布全部后续安排，新增课程需要再次采集；其他学期和跨学期实习应使用已核实的专门范围。

坏文件、旧文件或不完整响应不能覆盖当前完整课表；只有对应当前课表且通过检查的手机文件才会被作为可发送结果提供。

## 浏览器适配情况

| 浏览器 | 当前适配与验证范围 |
| --- | --- |
| Edge、Chrome、Firefox 的现代版本 | 已提供通用安装指引、基础功能检查和有超时保护的读取方式；本版学校实采均待验证。Chrome 的旧版真实采集记录不能替代本版验收 |
| QQ、360、搜狗等独立浏览器 | 先看安装页检查结果，仍需按具体版本实测；仅凭同一内核不能保证成功 |
| IE / IE 兼容模式、微信或 QQ 聊天内嵌网页 | 不在支持范围，请使用独立的现代浏览器普通窗口 |

基础检查通过只表示所需功能存在，不能保证学校登录、书签执行和文件下载已经通过。浏览器保存位置不同，可在助手选择文件继续；无需改浏览器设置。

快捷键参考：[Edge 官方说明](https://support.microsoft.com/en-us/edge/keyboard-shortcuts-in-microsoft-edge)、[Firefox 官方说明](https://support.mozilla.org/en-US/kb/bookmarks-firefox)。

## 文件与隐私

独立 EXE 默认把个人数据保存在当前 Windows 用户的 **%LOCALAPPDATA%/SHSMUScheduleAssistant**，与 EXE 分开；移动或更新 EXE 不会重建历史。也可主动选择原项目或独立空目录。

学生助手只在本地处理，不上传课表，不保存教务密码、Cookie 或会话存储。原项目已有的 WebCal 设置仍供命令行版使用，桌面版不触发上传。

分享给同学时发送上方下载链接或完整软件包，不复制个人数据目录。完整记录见 [验证说明](VERIFICATION.md)。
