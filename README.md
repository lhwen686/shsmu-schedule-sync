# 医学院课表助手

**双击一个软件，把本人的教务课表导入 iPhone 的 WakeUp。**

学生版面向 Windows 64 位电脑，不需要安装 Python、使用命令行或修改配置文件。使用平时登录教务的浏览器，适用于上海交通大学医学院本科教务系统 jwstu.shsmu.edu.cn。

**[下载 Windows 软件与使用说明](https://github.com/lhwen686/shsmu-schedule-sync/releases/tag/v1.0.0-rc4)**。在下载页选择“医学院课表助手.exe”，或下载包含软件和说明的完整包；无需从绿色 Code 按钮下载源码。

当前为 **1.0.0-rc4 候选版**。自动检查和实机验收分开记录，尚未完成的环节见 [学生版验收](STUDENT_ACCEPTANCE.md)。原命令行工具继续可用，安装与维护命令见 [维护说明](MAINTENANCE.md)。

## 第一次使用

1. 从上方下载页取得软件，双击 **医学院课表助手.exe**；如果下载了完整 ZIP 包，请先右键选择“全部解压缩”，再打开其中的同名 EXE。
2. 选择要导入的学期，**不用填写哪天结课**。当前默认 2026–2027 学年第 1 学期，助手按学校校历准备采集范围，并包含下学期开学前的寒假；实际有课到哪天由本人教务课表确定。
3. 点 **复制安装页地址**，在平时登录教务的浏览器地址栏粘贴并回车。安装页会先检查基础功能；按图示把绿色“同步医学院课表”按钮拖到书签或收藏夹栏，再回助手点 **我已添加课表按钮**。

Edge 叫“收藏夹栏”，Chrome 叫“书签栏”，Firefox 叫“书签工具栏”，可按 **Ctrl + Shift + B** 显示。添加和学校登录请使用同一个浏览器；换浏览器时重新添加按钮即可，助手里的历史无需搬动。安装页也提供手动替换旧书签的方法，助手不会修改浏览器或扩展。

## 以后更新课表

1. 在助手点 **获取我的课表**，看到“已准备好接收”。
2. 在添加了课表按钮的浏览器中正常登录 [教务首页](https://jwstu.shsmu.edu.cn/Home)，看到本人学号后点课表按钮。保持学校页面打开，等待几分钟，以网页实际进度为准。
3. 助手自动生成 WakeUp 文件。点 **找到要发到手机的文件**，将选中的 **wakeup.csv** 拖到微信“文件传输助手”或 QQ“我的手机”，由你点击发送。

## 在 iPhone 导入

1. 把收到的 wakeup.csv 保存到 iPhone 的“文件”App。
2. WakeUp → **导入课表 → Excel 导入 → 选取 CSV 文件**，导入到新课表。
3. 在助手查看 **iPhone 导入指引与作息**。开学日期根据教务教学周校验，WakeUp 所需周数按本次最后有课的教学周计算；照设置卡核对这些值及上课时间。
4. 检查第一周、晚课和不连续周次，核对后再自行处理旧课表，避免重复显示。

**电脑生成文件后，手机仍要手动导入。** CSV 不携带作息设置，也不会自动更新手机。全部实际课程起止时间都会与作息核对，模板中未获课程端点证实的时间标为推算。

配图步骤见 [使用说明](使用说明.html)。手机操作依据：[WakeUp CSV 导入](https://www.wakeup.fun/doc/import_from_csv.html)、[课表设置](https://www.wakeup.fun/doc/settings/schedule_settings.html)。

## 遇到问题

| 情况 | 在助手里怎么做 |
| --- | --- |
| 已先点书签，文件下载好了 | 点“文件已经下载”；取消选择会继续原来的等待 |
| 文件保存在别处 | “遇到问题”→“选择下载文件夹”，或直接选择已下载文件 |
| 换了浏览器后找不到课表按钮 | “遇到问题”→“重新查看书签安装引导”，在新浏览器添加并登录 |
| 安装页显示当前浏览器不能使用 | 按提示使用更新后的普通浏览器窗口，避开 IE 兼容模式 |
| 课表保存了，导入文件没生成 | 在设置中核对作息，再点“重新生成导入文件”，无需重新采集 |
| 登录账号与原课表不同 | 登录原账号；另一人选择独立空目录 |
| 以前使用过源码版 | 在首次引导或“设置 → 保存位置”选择原项目目录，沿用历史 |
| 学期变了 | 在设置中填写新学期及包含的最后一天，保存后按引导更新书签 |

当前秋季自动采集覆盖 2026-09-07 至 2027-02-21（含），依据学校校历的下一学期开学日。1 月 17 日是校历中的秋季教学期末，不是每个人的结课日；提前结课不会生成空课，寒假期间的同学课程也会读取。此范围不代表学校已经公布全部后续安排，新增课程需要再次采集；其他学期和跨学期实习应使用已核实的专门范围。

坏文件、旧文件或不完整响应不能覆盖当前完整课表；只有对应当前课表且通过检查的手机文件才会被作为可发送结果提供。

## 浏览器适配情况

| 浏览器 | 当前适配与验证范围 |
| --- | --- |
| Edge、Chrome、Firefox 的现代版本 | 已提供通用安装指引、基础功能检查和有超时保护的读取方式；本版学校实采均待验证。Chrome 的旧版真实采集记录不能替代本版验收 |
| QQ、360、搜狗等独立浏览器 | 先看安装页检查结果，仍需按具体版本实测；仅凭同一内核不能保证成功 |
| IE / IE 兼容模式、微信或 QQ 聊天内嵌网页 | 不在支持范围，请使用独立的现代浏览器普通窗口 |

基础检查通过只表示所需功能存在，不能保证学校登录、书签执行和文件下载已经通过。浏览器保存位置不同，可在助手选择文件继续；无需改浏览器设置。

快捷键参考：[Edge 官方说明](https://support.microsoft.com/en-us/edge/keyboard-shortcuts-in-microsoft-edge)、[Firefox 官方说明](https://support.mozilla.org/en-US/kb/bookmarks-firefox)。

## 文件与隐私

独立 EXE 默认把个人数据保存在当前 Windows 用户的 **%LOCALAPPDATA%/SHSMUScheduleAssistant**，与 EXE 分开；移动或更新 EXE 不会重建历史。也可主动选择原项目或独立空目录。

学生助手只在本地处理，不上传课表，不保存教务密码、Cookie 或会话存储。原项目已有的 WebCal 设置仍供命令行版使用，桌面版不触发上传。

分享给同学时只发送 EXE、使用说明和校验值，不复制个人数据目录。完整记录见 [验证说明](VERIFICATION.md)。
