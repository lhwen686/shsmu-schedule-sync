查看检查详情

  1. 在登录教务的浏览器中打开本页，将“同步医学院课表”拖到书签栏。
    Edge 叫“收藏夹栏”，Chrome 叫“书签栏”，Firefox 叫“书签工具栏”；这三种浏览器可按 Ctrl + Shift + B 显示。Safari 请选“显示 → 显示个人收藏栏”，把按钮拖入该栏。请在同一个浏览器完成添加和学校登录。
  2. 先运行“同步课表.cmd”，等待接收课表文件。
  3. 在同一浏览器登录教务首页，确认显示本人学号，再点击书签。读取完成后，本地窗口将继续处理。
    Safari 首次使用时，请先打开“我的课表”确认课程已显示，再回首页点击书签。

同步医学院课表

已下载课表时，可运行“导入已下载课表.cmd”选择文件，或将 JSON 拖到“同步课表.cmd”上，无需再次读取。

无法拖动时，可手动新建书签：名称填“同步医学院课表”，地址粘贴下方全部内容。

Safari：按住 Control 点按旧课表书签，选择“编辑地址”，粘贴上方完整网址。请保留开头的 javascript:；不要直接粘贴到智能搜索栏执行。

书签仅通过当前浏览器读取学校课表，不读取或导出密码、Cookie、会话存储，也不修改浏览器扩展。请将下载的 JSON 保存到本地窗口指定的文件夹。
